# Deployment dependencies for talk-github.
#
# This file is deliberately SHORT. It is not a copy of the parent project's
# requirements - this app imports far less, and a deployment that installs
# torch, chromadb and pandas for no reason is slow to build and easy to break.
#
# Two things are absent on purpose:
#   - No chromadb. The app uses LangChain's InMemoryVectorStore, so there is no
#     SQLite version requirement and no pysqlite3-binary shim to maintain.
#     See the comment at the top of repo_index.py.
#   - No GitPython. Repositories are downloaded as a zip over HTTPS, so no `git`
#     binary needs to exist on the host.
#
# Versions are pinned to what this was built and tested against. Loosen them
# deliberately, not by accident.
